# EVA AI

EVA é uma IA simples feita em Python para Termux/Linux.

## Instalação

Clone o projeto:

```bash
git clone https://github.com/IhatemyselfBR/Eva.AI.git
```

Entre na pasta:

```bash
CD eva
```

Instale as dependências:

```bash
pip install requests
```

## Como usar

Rodar EVA:

```bash
python brain.py
```

## Comandos avaliativos

| Comando | Função |
|---|---|
| $p| aumenta peso |
| $g | pequeno aumento |
| $ng | reduz peso |

## Sistema

A EVA:
- aprende respostas
- salva memória local
- usa pesos
- consulta internet

## Requisitos

- Python 3
- Termux ou Linux
- Internet
